# Wakeup Edison Website

Source code for Wakeup Edison's official website, hosted at [http://www.wakeupedisonnj.org/]([http://www.wakeupedisonnj.org/](url)).

## About

Wake Up Edison is a volunteer-run food drive collecting non-perishable goods for Hands of Hope, a food pantry serving 200+ families and 800+ adults and children in Edison Township, NJ. Amid rising food costs, unemployment, and cuts to federal pantry funding, Wake Up Edison organizes monthly collection drives and a standing drop-off location to help keep local shelves stocked for neighbors in need.

## How to update the site

1. Clone this repo: `git clone [repo URL]`
2. Make changes to the relevant files
3. Commit and push to `main`
4. Changes go live automatically within a few minutes via GitHub Pages
